# Low-tide folio · WAKE / rock_m
Original medium basalt outcrop, authored by Owwol with GPT-6.2 Astra. The shoulder is a westward undercut shelf, not a scaled sphere. A second bedding layer dips away and a lower tail breaks the outline. Two narrow top-joint moss seams and a separately glossy submerged toe should reward a close look without giving an unlit obstacle a beacon of its own.

**Runtime:** `art/models/rock_m.glb`. Root at world waterline, identity transforms, glTF +Y up, units metres. Maximum horizontal radius 3.2 m, peak 2.0 m above water. The model supplies no simulation collision mesh. Three untextured vertex-color material batches: rough basalt, wet basalt, and dark moss. 803 triangles; 92,604 bytes.

**Editable:** `rock_m.blend` contains production meshes, named vertex groups for individual beds/seams and the editable surface materials. `build.py` is the source of the authored contours, layer heights and palette. From the repo root with Blender (4.3 native exporter): `blender -b -t 2 -P art/sources/rock_m/build.py`. Review authored changes before replacing the master. Verify exports with `python3 art/sources/rock_m/verify.py` and `npm run art:check -- rock_m`. No external assets or add-ons.
