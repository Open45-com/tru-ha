# Until Tomorrow: puzzle props v1

Copy this whole folder as res://puzzle/ into the shared Godot 4 art project. Each prop has an editable SVG and an instantiable scene. In mirror.tscn, the mount stays fixed. Set the face child to 0 degrees for a forward slash or +90 degrees for a backslash.

Use web/anchors.json with the transparent PNGs. Coordinates are pixels from each PNG's top-left. The emitter anchor is the beam exit. Both lanterns have 78 x 96 bounds and beam target [39, 53]; attach the lamp by hanging point [39, 9]. Keep beam, grid, labels and controls in the web client.

The separate preview shows both pilot boards at 360 px over Choco's offshore blockout. It is a fit check, not a live phone playtest. Art in this bundle consists of original vector shapes. The harbor blockout is used only in the separate review preview.
